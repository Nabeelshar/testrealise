Report a crash

PlayDeck sends no automatic crash reports — this form is how a report reaches us. Fill it in, press Open report on GitHub, and your report opens as a pre-filled GitHub issue. Submit it there, then attach your log file to the issue (step 2 below).

Before you report:
  1. In the app, reproduce the crash once if you can, then use Share Logs to save the redacted log ZIP. The app scrubs account names, tokens and secrets from it before sharing.
  2. After submitting the issue, drag the log ZIP onto the issue page to attach it. Logs are what let us actually fix the bug.
  3. Reports are public. Never paste passwords, tokens, or anything private. If a log line looks private, delete that line before attaching.

This opens github.com with your report pre-filled. Nothing is sent until you press Submit there.

No GitHub account? Browse existing issues — your bug may already be reported. Or ask on an existing issue instead of opening a duplicate.
